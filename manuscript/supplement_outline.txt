Supplement outline

Purpose of the supplement
- Establish the technical credibility of the main claims.
- Show that the preferred interpretation is robust to alternative datasets and modeling choices.
- Provide the long-form methodological and diagnostic material that would interrupt the main narrative.

How the supplement should read
- Not as a second main paper.
- Not as a catalog of every output.
- It should read as a structured evidentiary appendix that supports three main-text claims:
  1. the Neher/Bedford H3N2 model is a valid benchmark reconstruction,
  2. the filtered Harvey/WIC H3N2 model is the best modern consensus model,
  3. the main conclusions survive reasonable sensitivity analyses.

Recommended supplement structure

1. Supplementary Methods

1.1 Data sources and inclusion criteria
- Define the Neher/Bedford H3N2 input data.
- Define the Harvey/WIC H3N2 input data.
- Define the filtered Harvey/WIC subset and state explicitly what is excluded.

1.2 Sequence matching, alignment, and numbering
- Describe sequence matching and retained modeled rows.
- Describe alignment and HA1 extraction.
- State clearly that site numbering uses mature HA numbering and excludes the N-terminal 16-residue signal peptide.

1.3 Model specification
- Explain the additive baseline for Neher/Bedford H3N2.
- Explain the additive correction plus learned context structure for Harvey/WIC.
- Define site-state and substitution encodings.
- Define the role of temporal distance.

1.4 Validation and held-out evaluation
- Fold design
- grouped holdouts
- Neher-style grouped-virus analog evaluation
- retained performance metrics

1.5 SHAP ranking and stability
- how feature-level SHAP values were aggregated
- how site-level summaries were constructed
- how fold-wise stability was defined

1.6 Cross-study comparison design
- define the reference sets and external analyses:
  Koel,
  Neher/Bedford,
  Harvey,
  McWhite,
  PLoS/Meyer,
  LightGBM+SHAP passage,
  LightGBM+SHAP date,
  unpassaged entropy,
  unpassaged dN/dS
- clarify the benchmark logic used in the main figure

1.7 Sensitivity analyses
- unfiltered Harvey/WIC
- patristic-distance models
- optional note on why patristic distance is treated as a sensitivity covariate rather than a primary explanatory representation

2. Supplementary Results organization

Section A
Primary Neher/Bedford H3N2 support
- Goal:
  show that the benchmark model is predictive, stable, and consistent under grouped holdout
- Figures:
  S1-S4
- Key message:
  the main-text Neher/Bedford interpretation is well-supported

Section B
Primary filtered Harvey/WIC H3N2 support
- Goal:
  show that the preferred modern model is predictive, stable, and appropriately residualized
- Figures:
  S5-S9
- Key message:
  the filtered Harvey/WIC model is not just interpretable, it is technically well-supported

Section C
Sensitivity analyses
- Goal:
  show why the paper emphasizes filtered Harvey/WIC and deprioritizes patristic variants
- Figures:
  S10-S15
- Key messages:
  unfiltered WIC is biologically noisier;
  patristic distance changes prediction less than it changes interpretability;
  neither sensitivity analysis overturns the main conclusions

3. Supplementary Tables

Table S1
- broader model-performance summary across local analyses
- use to document the model grid without narrating it extensively in the main paper

Table S2
- reference-overlap summary
- use as the numerical companion to the main cross-study figure

Optional later tables if needed
- expanded Neher supplementary-site benchmark
- longer integrated literature-comparison subsets
- substitution-model summaries for the two primary datasets

5. Supplement writing priorities
- Put the strongest support for the main models first.
- Use captions to do most of the explanatory work.
- Keep prose between figures short and highly interpretive.
- Repeatedly remind the reader which analyses are primary and which are sensitivity analyses.

6. Supplement drafting order
- Write Supplementary Methods first.
- Then write short lead paragraphs for Sections A, B, and C.
- Then write Table S1 and Table S2 captions/notes.
- Then write all figure captions in the order they appear.
- Only after that add any extra interpretive text that seems necessary.

7. Supplement closing principle
- A reviewer should come away thinking:
  the main paper’s preferred models were chosen for coherent biological reasons,
  the alternatives were examined seriously,
  and the conclusions do not depend on a fragile modeling choice.
